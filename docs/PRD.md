# OceanCraft Configurator — Product Requirements

## Goal
Web 3D dayboat configurator driven by authored GLB layers: live materials, optional details, price, save config.

## Core modules (aligned to GLB names)
- Hull gelcoat → `Hull_Main`
- Accent stripe → `Accent_Stripe`
- Sunpad → `Sunpad_Bow`
- Teak deck → `Interior_Deck` (tint, keep wood map)
- Cockpit soft goods → `Interior_Cockpit` / `Interior_Dash` / `Interior_Vinyl`
- Details (toggle) → `Detail_*`

Fixed for now: `Glass_Windshield`, `Rail_Railing`
